# Godofredo e a Floresta Encantada

Jogo da família, baseado no livro *Godofredo e a Floresta Encantada*, de José Valmir Moura Júnior e Anna Portela de Aguiar Moura.

Jogar: https://mourassss-gif.github.io/floresta-encantada/

O jogo inteiro está em `index.html` (um arquivo só, funciona offline). O progresso fica salvo no navegador de quem joga.
